## 审查修复的回归范围

- durable handoff 记录父子累计调查轮次、各缺口依据、剩余轮次和补查是否已用；工具调用、读取、
  输出量上限只是额外约束，不能兑换轮次或因委派重新获得。缺失消耗数据不得当作零。
- 旧交接历史消耗 unknown、无剩余缺口且安全前提已确认时，允许直接编辑/验证，不授予新调查或补查额度；不能为补历史计数阻塞就绪切片，也不能跳过当前安全复核。
- 分别断言 spawn-execute 与 delegation-contract 的实际内容要求，不仅检查参考链接。
- 上述静态断言保护指令不退化；Packet 示例仅验证格式兼容，均不证明代理实际遵循或耗时改善。
